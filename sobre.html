Sobre Nós

O Cachorro Leva-e-Seca é um projeto desenvolvido pelos alunos do curso de Front-End do SENAI, em 2026, como parte das atividades práticas realizadas em aula.

Estamos dando nossos primeiros passos no mundo da programação, aprendendo conceitos básicos de desenvolvimento web e utilizando tecnologias como HTML e CSS para criar páginas organizadas, acessíveis e visualmente agradáveis.

A proposta deste projeto é colocar em prática os conhecimentos adquiridos durante o curso, desenvolvendo um site fictício para um pet shop, com informações sobre serviços, preços e formas de contato.

Mais do que criar uma página na internet, buscamos desenvolver nossas habilidades, estimular a criatividade e adquirir experiência para os próximos desafios na área de tecnologia.

🐾 Aprendendo hoje, desenvolvendo o futuro!

Este é apenas o começo da nossa jornada na programação. Cada projeto é uma oportunidade de aprender, praticar e evoluir.
